# Worldesium downloads

Official installers and signed desktop update manifests for **Worldesium**.

- [Play Worldesium](https://apexstare.online/)
- [Download and installation options](https://apexstare.online/download.html)
- [Latest Windows release](https://github.com/NestcodeShield/worldesium-releases/releases/latest)
- [Devlog 0.3](https://apexstare.online/updates/0.3.html)

## Windows

Download the latest `Worldesium_…_x64-setup.exe` from Releases, install it and sign in with your game account. The client connects to the same hosted world as the browser game. An internet connection is required.

The app checks the public `latest.json` manifest at startup and verifies update signatures before installation. Updates are offered for confirmation.

## Phones and tablets

Worldesium can be added to the Home Screen from Safari on iPhone/iPad or installed from Chrome on Android. See the installation page above for steps.

This repository distributes desktop binaries and update metadata. Please report game issues through the community links on the website.
